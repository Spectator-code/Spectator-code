### 🛡️ About Me

Hey there! 👋 I'm **Arcnde**. I'm an enthusiastic **Junior Blue Team** and **Junior Red Team** security researcher and developer. 

- ⚔️ **Offensive Security (Red Team)**: Performing vulnerability assessments, discovering attack surfaces, and analyzing web applications using **Burp Suite** and security tools.
- 🛡️ **Defensive Security (Blue Team)**: Monitoring, analyzing network traffic, understanding attack vectors, and implementing robust defenses.
- 💻 **Software Engineering**: Writing clean and secure code with **React (JSX/TSX)**, **TypeScript**, **Java**, **Laravel**, **PHP**, and **HTML5**.
- 🎯 **Continuous Goal**: Bridging the gap between software development and cybersecurity by building systems that are resilient by design.
